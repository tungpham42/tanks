# Tanks (Battle City style) — CRA + TypeScript + SVG + Web Audio

    npx create-react-app tanks --template typescript
    cd tanks
    # copy audio.ts, game.ts, App.tsx, App.css into ./src (replace App.tsx / App.css)
    npm start

Controls: Arrows/WASD move, Space (or J/K) fire, P pause, Enter start/retry.
Protect the eagle, destroy 20 enemy tanks per stage. Gray = basic, white = fast, green = armored (4 hits).
